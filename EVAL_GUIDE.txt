OVERVIEW:
--------------------------------------------------------------------------------
The Nym Evaluation Engine (`/eval`, `!eval`, and `!evalfile`) is an advanced, 
async-native developer runtime system designed exclusively for Bot Owners.

It executes Python code dynamically inside Nym's live event loop, providing 
direct access to the bot instance, SQLite database, Upstash Redis cache, 
Discord API models, and Python standard library.

================================================================================
SECTION 1: EVAL SETUP & ARCHITECTURE
================================================================================

1. OWNER PERMISSIONS & AUTHORIZATION:
   - Evaluation commands require Bot Owner privileges (`@commands.is_owner()`).
   - Configure your Discord User ID in `.env`:
     `OWNER_ID=450864876416401419`

2. IMPLICIT LAST-LINE RETURN (AST TRANSFORMATION):
   - The Evaluation Engine automatically parses your code's Abstract Syntax Tree (AST).
   - If the last statement is an expression (e.g. `bot.latency * 1000` or `await db.fetch_all(...)`),
     it is automatically evaluated and returned without needing a `return` keyword!

3. STDOUT CAPTURE & TELEMETRY:
   - Standard `print(...)` output is captured via `sys.stdout` and displayed.
   - Execution duration is measured down to the millisecond.

4. AUTOMATIC ATTACHMENT FOR LARGE OUTPUTS:
   - If the evaluation output or stack trace exceeds Discord's 2,000 character limit,
     Nym automatically packages the telemetry into a `.txt` or `.log` file attachment.

5. FILE ATTACHMENT EVALUATION (`!evalfile`):
   - Upload any `.py` or `.txt` file with `!evalfile` as the message content to execute 
     full-length multi-line scripts.

================================================================================
SECTION 2: PRE-BOUND ENVIRONMENT SHORTCUTS
================================================================================

When writing eval snippets, the following variables are pre-bound in your execution context:

- `bot`      : Py-Cord NymBot client (`commands.Bot`)
- `ctx`      : Invoking Command Context / ApplicationContext
- `guild`    : Current Discord Server (`ctx.guild`)
- `channel`  : Current Text Channel / Thread (`ctx.channel`)
- `author`   : Invoking Member / User (`ctx.author`)
- `message`  : Invoking Message object (alias: `msg`)
- `me`       : Nym's Member object in current guild (or `bot.user`)
- `db`       : SQLite Database Manager (`bot.db`)
- `upstash`  : Upstash Redis REST Client (`bot.upstash`)
- `discord`  : `discord` Py-Cord package
- `asyncio`  : Python `asyncio` module
- `datetime` : `datetime.datetime` class
- `timedelta`: `datetime.timedelta` class
- `time`, `os`, `sys`, `json`, `re`, `math`, `logging` : Standard library modules

--------------------------------------------------------------------------------
CATEGORY 1: BASIC TELEMETRY & MESSAGING
--------------------------------------------------------------------------------

1. Print simple text to console/channel:
   nym eval print("Hello from Nym Core!")

2. Send a text message to current channel:
   nym eval await ctx.send("The neural link is active.")

3. Check WebSocket Latency (Implicit Return):
   nym eval f"{round(bot.latency * 1000, 2)} ms"

4. React to your command message:
   nym eval await message.add_reaction("🔥")

5. Check server count & total member count:
   nym eval f"Guilds: {len(bot.guilds)} | Total Members: {sum(g.member_count for g in bot.guilds)}"

6. Send a styled Nekotina embed:
   nym eval
   from src.utils.embeds import EmbedBuilder
   embed = EmbedBuilder.info("System Test", "Operational check passed.", author=author)
   await ctx.send(embed=embed)

CATEGORY 6: ROLE MANAGEMENT
--------------------------------------------------------------------------------

1. Add a role to a user:
   nym eval await guild.get_member(USER_ID).add_roles(guild.get_role(ROLE_ID))

2. Remove a role from a user:
   nym eval await guild.get_member(USER_ID).remove_roles(guild.get_role(ROLE_ID))

3. Give a role to all human members in the server:
   nym eval
   role = guild.get_role(ROLE_ID)
   for m in guild.members:
       if not m.bot and role not in m.roles:
           await m.add_roles(role)

4. Strip a role from all members:
   nym eval
   role = guild.get_role(ROLE_ID)
   for m in role.members:
       await m.remove_roles(role)

CATEGORY 7: SQLITE DATABASE OPERATIONS (`db`)
--------------------------------------------------------------------------------

1. Fetch all records from SQLite `users` table:
   nym eval await db.fetch_all("SELECT * FROM users")

2. Fetch all configured sticky messages from SQLite:
   nym eval await db.fetch_all("SELECT * FROM sticky_messages")

3. Query server prefix setting from SQLite:
   nym eval await db.fetch_one("SELECT prefix FROM guild_settings WHERE guild_id = ?", (guild.id,))

4. Insert or update user record manually:
   nym eval await db.execute("INSERT OR REPLACE INTO users (user_id, username) VALUES (?, ?)", (author.id, author.name))

5. Delete sticky message record from database:
   nym eval await db.execute("DELETE FROM sticky_messages WHERE channel_id = ?", (channel.id,))


--------------------------------------------------------------------------------
CATEGORY 8: UPSTASH REDIS CACHE OPERATIONS (`upstash`)
--------------------------------------------------------------------------------

1. Ping Upstash Redis REST API and return latency:
   nym eval await upstash.ping()

2. Get last bot heartbeat timestamp from Upstash:
   nym eval await upstash.get("nym:bot_heartbeat")

3. Get cached server prefix from Upstash:
   nym eval await upstash.get(f"prefixes:{guild.id}")

4. Set custom key in Upstash Redis with 1-hour expiration (3600s):
   nym eval await upstash.set("nym:custom_test", "active_data", ex_seconds=3600)

5. Delete a key from Upstash Redis (set 1-second TTL):
   nym eval await upstash.set("nym:custom_test", "", ex_seconds=1)

--------------------------------------------------------------------------------
CATEGORY 10: SCRIPT FILE EVALUATION (`!evalfile`)
--------------------------------------------------------------------------------

To execute long, complex multi-line scripts without typing them line-by-line:

1. Create a `.py` file on your computer (e.g., `audit_script.py`):
```python
print("--- RUNNING FULL SYSTEM AUDIT ---")
print(f"Guild Name: {guild.name} (ID: {guild.id})")
print(f"Total Members: {guild.member_count}")

# Check Database
users = await db.fetch_all("SELECT * FROM users")
print(f"Database user records: {len(users)}")

# Check Upstash Redis
heartbeat = await upstash.get("nym:bot_heartbeat")
print(f"Upstash Heartbeat: {heartbeat}")

# Send Summary Embed
from src.utils.embeds import EmbedBuilder
embed = EmbedBuilder.success("Audit Completed", f"Checked {len(users)} users & Redis heartbeat.")
await channel.send(embed=embed)
```

2. Drag and drop `audit_script.py` into Discord.
3. Type `!evalfile` as the message comment and send.
4. Nym executes the script and posts the complete output telemetry!
