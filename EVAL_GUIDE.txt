OVERVIEW:
--------------------------------------------------------------------------------
The Nym Evaluation Engine (`/eval` and `!eval`) is a high-density, async-native
runtime code execution system built exclusively for Bot Owners.

It allows you to inspect bot state, execute administrative actions, query SQLite 
and Upstash Redis, manage members and roles, send interactive messages, and run
custom scripts directly inside Nym's live event loop.

KEY FEATURES:
- IMPLICIT LAST-LINE RETURN: The last expression in your snippet (e.g. `bot.latency`)
  is automatically returned even if you don't write `return`.
- STDOUT CAPTURE: Anything printed using `print(...)` is captured and displayed.
- RICH CONTEXT ENVIRONMENT: Shortcuts for `bot`, `ctx`, `guild`, `channel`, `author`,
  `message`, `me`, `db`, `upstash`, `discord`, `asyncio`, `datetime`, `timedelta`, etc.
- FILE EVALUATION (`!evalfile`): Attach a `.py` file to a message to execute full scripts.
- TELEMETRY & TRACEBACK: Execution time measured in milliseconds with automatic `.txt`
  log attachment for long outputs.

================================================================================
AVAILABLE CONTEXT ENVIRONMENT SHORTCUTS
================================================================================
- `bot`      : Active Py-Cord NymBot client instance
- `ctx`      : Current command Context / ApplicationContext
- `guild`    : Current Discord Guild (Server) object
- `channel`  : Current TextChannel / Thread object
- `author`   : Invoking User / Member object
- `message`  : Invoking Message object (alias: `msg`)
- `me`       : Nym's Member object in the guild (or `bot.user`)
- `db`       : Async SQLite DatabaseManager (`bot.db`)
- `upstash`  : Async Upstash Redis REST client (`bot.upstash`)
- `discord`  : Py-Cord module
- `asyncio`  : Python `asyncio` module
- `datetime` : `datetime.datetime` object
- `timedelta`: `datetime.timedelta` object
- `os`, `sys`, `time`, `json`, `re`, `math` : Python standard library modules

================================================================================
CATEGORY 10: FILE ATTACHMENT SCRIPT EVALUATION (!evalfile)
================================================================================

Attach any `.py` script to a Discord message with `!evalfile` as the comment:

Example Script Content (`test_script.py`):
```python
print("--- RUNNING ADVANCED AUDIT SCRIPT ---")
users = await db.fetch_all("SELECT * FROM users")
print(f"Total database user records: {len(users)}")
for u in users:
    print(f"- User ID: {u['user_id']} | Username: {u['username']}")

heartbeat = await upstash.get("nym:bot_heartbeat")
print(f"Upstash Heartbeat: {heartbeat}")
```

Execution:
1. Drag and drop `test_script.py` into Discord channel.
2. Type `!evalfile` as the message content and press Send.
3. Nym will execute the attached script and return full telemetry!
